# Pertemuan 02: Elemen Dasar Pemrograman

Materi pertemuan 02 pada mata kuliah Pemrograman Berorientasi Objek (OOP) menggunakan bahasa Python.

## Apa yang Dipelajari?
- Elemen dan sintaks dasar pemrograman Python.
- Penggunaan tipe data, variabel, dan struktur kontrol.
- Implementasi class sederhana seperti `Mahasiswa` dan pengenalan method.

## Cara Menjalankan Program
1. Pastikan Anda sudah menginstal Python di komputer Anda (silakan merujuk ke panduan instalasi di **Pertemuan 01** jika belum).
2. Buka terminal atau command prompt.
3. Arahkan direktori (gunakan perintah `cd`) ke folder `Pertemuan 02`.
4. Jalankan program utama dengan perintah:
```bash
python Main.py
```
Atau jalankan file latihan spesifik:
```bash
python ElemenDasarJava.py
```
*(Catatan: file `.py` adalah kode Python)*
