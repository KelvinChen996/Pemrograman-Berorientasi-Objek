# Pertemuan 03: Landasan Konsep OOP

Materi pertemuan 03 pada mata kuliah Pemrograman Berorientasi Objek (OOP) menggunakan bahasa Python.

## Apa yang Dipelajari?
- Pendalaman landasan konsep Class dan Objek.
- Cara mendefinisikan Atribut (state) dan Method (behavior) dalam sebuah class.
- Implementasi studi kasus sederhana menggunakan blueprint (misalnya `Produk`).

## Cara Menjalankan Program
1. Pastikan lingkungan Python Anda sudah siap.
2. Buka terminal atau command prompt.
3. Navigasi ke folder `Pertemuan 03`.
4. Eksekusi program utama menggunakan perintah:
```bash
python Main.py
```
