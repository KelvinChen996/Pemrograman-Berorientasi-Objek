# Pertemuan 01: Pengantar Pemrograman Berorientasi Objek (OOP)

Materi pertemuan 01 pada mata kuliah Pemrograman Berorientasi Objek (OOP) menggunakan bahasa Python.

## Apa yang Dipelajari?
Pada pertemuan ini, dipelajari konsep dasar OOP meliputi:
- Pemahaman dasar tentang konsep Pemrograman Berorientasi Objek (Class dan Objek).
- Analogi OOP di dunia nyata.
- Pengenalan Empat Pilar OOP (Encapsulation, Inheritance, Polymorphism, Abstraction).
- Perbandingan antara pemrograman prosedural dan berorientasi objek.

## Persiapan dan Instalasi
Untuk menjalankan kode program Python pada pertemuan ini (dan pertemuan selanjutnya), Anda perlu menyiapkan hal-hal berikut:
1. **Python 3.x**: Unduh dan install dari situs resmi [python.org](https://www.python.org/downloads/). 
   *Penting:* Pastikan Anda mencentang opsi **"Add Python to PATH"** saat melakukan instalasi (khusus pengguna Windows).
2. **IDE / Text Editor**: Sangat disarankan untuk menggunakan Visual Studio Code (VS Code), PyCharm, atau text editor pilihan Anda lainnya.
3. Ekstensi Python untuk IDE (jika menggunakan VS Code) untuk mempermudah auto-complete dan debugging.

Untuk mengecek apakah Python sudah terinstal dengan benar, buka Terminal atau Command Prompt lalu jalankan perintah:
```bash
python --version
```

## Cara Menjalankan Program
1. Buka terminal atau command prompt.
2. Arahkan direktori (gunakan perintah `cd`) ke dalam folder `Pertemuan 01`.
3. Jalankan file Python yang diinginkan (misalnya `Main.py`) dengan perintah:
```bash
python Main.py
```
*(Catatan: Anda dapat mengganti `Main.py` dengan nama file Python lainnya yang ada di dalam folder ini)*
