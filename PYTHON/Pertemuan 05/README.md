# Pertemuan 05: Konstruktor & Inisialisasi Objek

Materi pertemuan 05 pada mata kuliah Pemrograman Berorientasi Objek (OOP) menggunakan bahasa Python.

## Apa yang Dipelajari?
- Memahami konsep konstruktor untuk memberikan nilai awal saat objek dibuat.
- Penggunaan dunder method `__init__` sebagai metode konstruktor di Python.
- Inisialisasi atribut instance objek dengan contoh implementasi seperti kelas `Mahasiswa` dan `MataKuliah`.

## Cara Menjalankan Program
1. Buka terminal atau command prompt.
2. Arahkan (cd) ke folder `Pertemuan 05`.
3. Jalankan skrip program utama:
```bash
python Main.py
```
