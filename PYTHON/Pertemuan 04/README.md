# Pertemuan 04: Enkapsulasi & Desain Class

Materi pertemuan 04 pada mata kuliah Pemrograman Berorientasi Objek (OOP) menggunakan bahasa Python.

## Apa yang Dipelajari?
- Konsep Enkapsulasi (Encapsulation) untuk menyembunyikan detail implementasi (data hiding).
- Penggunaan konvensi penamaan (seperti `_` dan `__`) untuk Access Modifier (Public, Private, Protected) di Python.
- Praktik terbaik (best practices) dalam merancang dan mendesain class.

## Cara Menjalankan Program
1. Buka terminal atau command prompt.
2. Navigasi ke folder `Pertemuan 04`.
3. Untuk menjalankan program utamanya, ketikkan:
```bash
python Main.py
```
Anda juga dapat menjalankan file lain secara terpisah, misalnya:
```bash
python EnkapsulasiDesainClass.py
```
